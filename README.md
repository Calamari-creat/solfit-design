# SolFit — Design Base de Loja (Praia & Academia)

Layout de referência para loja de roupas de praia e academia, criado para ser aplicado como base visual na plataforma **Nuvemshop**.

## 👀 Ver o design

Abra o arquivo principal publicado no GitHub Pages (link no topo do repositório) ou `index.html`.

## 📂 Arquivos

| Arquivo | O que é |
|---|---|
| `index.html` | Mockup completo da home da loja (abrível no navegador) |
| `guia-nuvemshop.md` | Guia passo a passo para aplicar no tema da Nuvemshop (cores, fontes, estrutura e configurações) |
| `design-system/MASTER.md` | Documento do design system (tokens, paleta, tipografia, anti-padrões) |

## 🎨 Identidade visual

- **Fontes:** Barlow Condensed (títulos) + Barlow (corpo) — Google Fonts
- **Paleta:** verde `#059669` (praia/confiança) + laranja `#EA580C` (CTA/ofertas) sobre fundo `#ECFDF5`
- **Requisitos:** responsivo (375px → desktop), ícones SVG, contraste AA e `prefers-reduced-motion`

## 🚀 Como usar

1. Abra `index.html` no navegador
2. Siga o `guia-nuvemshop.md` para replicar o layout no editor de temas da Nuvemshop
3. Substitua os placeholders coloridos pelas fotos reais dos produtos (proporção 3:4)
